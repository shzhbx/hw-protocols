01

它是什么：会漏电的电容阵列

What & Why

拆开名字：同步——所有命令按时钟 CK 节拍走；动态——每个 bit 存在一个电容里，电容会漏电，必须周期性刷新； 双倍数据率——时钟上下沿各传一次数据。下面这个电容，就是整个 DRAM 帝国的最小单元。

DDR SDRAM（Double Data Rate SDRAM，2000 年接替 SDR SDRAM）是 PC、手机、服务器主内存的标准答案。 一个 bit 的全部家当 = 1 个访问晶体管 + 1 个电容（1T1C），折合每位约 1.1 个晶体管—— 这就是 DRAM 能做到 GB 级容量 + 便宜的根源。电容只存几十 fF 电荷，读出时电荷倾泻到位线， sense amplifier 从几十毫伏的摆动里判断 0/1 并放大锁存——读出是破坏性的，行关闭前必须回写。

为什么主内存不用别的？SRAM 一个 bit 要 6 管触发器，快且不用刷新，但面积约大 6 倍、贵一个数量级， 只配当 CPU cache；NAND Flash 非易失又便宜，但写前要擦、按块访问、寿命有限、随机延迟差三个数量级。 主内存要的 容量 / 带宽 / 价格 三角，只有 DRAM 全占。代价是管理复杂： 行要先 ACTIVATE 才能读写、用完要 PRECHARGE 关闭、 全片每 64 ms 刷新一遍——本页剩下的部分，都在讲怎么把这套"慢动作"包装成 GB/s 流水线。

动画里关掉刷新试试：电荷一路漏到判 0 阈值之下，bit 从 1 翻成 0——数据蒸发。 这不是夸张：JEDEC 规定普通档颗粒必须在 64 ms 内完成全部行刷新（高温档 32 ms），控制器平均每 7.8 µs 就要发一条 REFRESH（05 节细讲）。

FACT / A

1T1C · 密度的本钱 1T1C

每位一个晶体管一个电容，单元面积只有 SRAM 的几分之一。同一片晶圆，DRAM 容量轻松做到 SRAM 的几十倍——主内存的经济学全靠它。

FACT / B

漏电 · "动态"的由来 64 ms

电容电荷经 PN 结与介质缓慢泄漏，几十 ms 内就漏到无法判别。所以叫"动态"存储器：数据是靠不断刷新这种动作维持的，不是静止保存的。

FACT / C

破坏性读出 RESTORE

读一行 = 把电荷倒进 sense amp 放大，原电荷被破坏。行缓冲驻留期间 amp 持续回写；预充电前必须完成 restore，否则这行数据就真丢了。

FACT / D

同步接口 CK ↑

命令与地址在 CK 上升沿采样（SDR 时代数据也是）；DDR 起只有数据搬到 DQS 的双沿。一切时序参数（tRCD/CL/tRP…）都以 CK 周期为单位。

Dual-Edge Sampling

同一个 133 MHz 时钟：SDR 每周期在上升沿采 1 个 bit；DDR 上下沿各采 1 个——频率没提，吞吐翻倍。 切换模式看 红色探针（上升沿采样）与琥珀探针（下降沿采样）： 同样 32 bit 数据，总线占用从 32T 缩到 16T。

频率不够 · 沿来凑WHY DDR EXISTS

并行总线提频的敌人是走线与反射——133 MHz 之上 SI 代价陡增。DDR 的答案：把每个周期切成上下两半各传一 bit。 速率单位从此改叫 MT/s（百万次传输/秒）：DDR266 的 CK 其实只有 133 MHz。 后续各代再靠预取（prefetch）加码：内部阵列一次取 2n/4n/8n/16n 位，用慢阵列喂快 I/O（06 节）。

致命细节——源同步：不要用 CK 去采 DQ。数据与 CK 的相位关系经过走线后不可控；DQS 与 DQ 同源、同走线、同负载， 到达时间一起漂移，采样永远跟着数据走——这就是 source-synchronous（源同步）。SDR 没有 DQS，所以速率天花板极低。
03

阵列组织 · Bank / Row / Column 三级寻址

Array Organization

地址被拆成 bank → 行 → 列 三级。点「下一步」看完一行数据的完整生命周期： 激活（ACTIVATE）把整行复印进行缓冲 → 列读写直接怼行缓冲 → 预充电（PRECHARGE）关行写回。 行缓冲就是"一整行的免费缓存"——同行再取一列，几乎不要钱。

IDLE · 待命

所有字线关断。每个 bit 是「一个晶体管 + 一个电容」：电荷封在电容里，与世隔绝。位线被预充到 VDD/2，行缓冲为空。此时只能接收 ACTIVATE。

命中行缓冲 = 免费的缓存

行命中（同行换列）：只付 tCCD ≈ 4T 的列间隔；行未命中（换行）：PRE(tRP) + ACT(tRCD) + READ(CL)， DDR3-1600 档约 25T+ 起步——差 6 倍以上。控制器与 MMU 的行替换策略，就是在赌局部性。

组织bank 数量在涨

DDR2/3：8 banks；DDR4：16 banks 分 4 组 bank group（组间可背靠背）；DDR5：32 banks / 8 组。 bank 越多，控制器越能把 tRP/tRCD 藏进其他 bank 的工作里——第 ⑦ 步看交错流水线。

ACTIVATE 到 READ/WRITE 的最小间隔：sense amp 放大锁存整行需要的时间。DDR3-1600 典型 11T ≈ 13.75 ns。不够就硬读 = 04 节动画里的违例。

CL列地址到数据 · CAS Latency

READ 到 DQ 吐出第一个 bit 的延迟，编程进模式寄存器 MRS。它是"预约制"延迟：数据一定准点到达——这也是控制器敢做深度流水线的前提。

tRP · tRAS · tRC关行与行周期

tRP：PRE 后 bank 再次可 ACTIVATE；tRAS：行最短打开时间（含回写）；tRC = tRAS + tRP = 同一 bank 两次激活最小间隔。换行访问的全部代价都在这三个参数里。

05

刷新 · 与漏电的永恒战争

Refresh · REFI & tRFC

电容漏电不停，刷新就不能停：控制器平均每 7.8 µs 发一条 REFRESH（64 ms ÷ 8192 行），每次占用 tRFC 不接客。把温度滑块拖过 85 °C，看 REFI 如何减半到 3.9 µs——漏电随温度指数加速。

FACT / A

7.8 µs 从哪来 64ms/8192

普通档颗粒要求 64 ms 内刷完全部行。8192 行 ÷ 64 ms → 平均间隔 7.8 µs，折合每秒约 12.8 万次 REF。每次 REF 只刷一行，由颗粒内部刷新计数器自动递增。

FACT / B

高温 2x 刷新 >85 °C

85–95 °C 扩展温度档漏电加速，retention 减半 → REFI 缩到 3.9 µs。颗粒内置温度传感器告诉控制器该切档；服务器 BIOS 里的 "Refresh Rate" 选项就是它。

FACT / C

tRFC 随容量涨 350ns+

每 REF 刷一行，行越大越多 bank 要预充，tRFC 越长：DDR3 4Gb ≈ 260 ns、DDR4 8Gb ≈ 350 ns。刷新约占 4–5% 带宽；DDR4/5 用同 bank 刷新（same-bank refresh）只阻塞一个 bank 来减伤。

FACT / D

自刷新 SELF REFRESH

CKE 拉低进入 self-refresh：颗粒自己给自己发 REF，控制器与时钟可全部关闭——休眠保数据的唯一办法。LPDDR 再加 PASR（部分阵列自刷新）与 deep sleep，只留要用的 bank，休眠功耗再砍。

LPDDR / A

DVFS · 动态电压频率调节 dvfs

LPDDR4/5 的控制器可随负载在多组「频率×电压」点之间切换（如 3200↔1600↔866 MT/s），待机时用低压低频档，功耗随 V²·f 直接下坠。

LPDDR / B

部分阵列自刷新 PASR

休眠时只保留实际在用的 bank 继续刷新，其余阵列断电——代价是唤醒后那些区域数据失效。配合 deep sleep 模式，休眠电流压到几百 µA 级。

LPDDR / C

IO 电压狂压 0.5 V

LPDDR4X 把 VDDQ 压到 0.6 V、LPDDR5 再到 0.5 V：IO 摆幅减半，驱动功耗约降四成。摆幅小了噪声容限也小，所以 LPDDR5 加了 link ECC 兜底。

LPDDR / D

PoP 封装 · 走线趋近于零 PoP

颗粒叠在 SoC 顶上，球距不到 0.5 mm——走线短到 SI 问题几乎消失，才能在 0.5 V 摆幅下跑 8533 MT/s。代价：不可插拔、不可升级。

07

信号完整性与初始化训练

Signal Integrity & Training

3200 MT/s 时一个数据位只有 312 ps 宽——反射、串扰、走线偏斜随便一个都能吃掉它。 ODT、VTT、fly-by 拓扑与初始化训练，是保住这只"眼睛"的四大件。

ODT On-Die Termination

DDR2 引入：把终端电阻做进颗粒，写数据时打开远端（颗粒）的 RTT 吸收反射，读时反过来用控制器端 ODT。 阻值经 ZQ 校准（参考 240 Ω）随工艺/温度修调。主板从此少贴几十颗电阻。

VTT Termination Voltage

SSTL 接口（DDR2/3）的地址、命令、时钟线终端到 VDDQ/2 专用电源轨。它要吞大电流（安培级），主板用专门 VTT 稳压器供电——服务器板上那颗烫手的芯片常就是它。

Fly-by 拓扑 Daisy Chain

地址/控制/时钟从主控出发依次路过每颗颗粒：走线短、分支少、反射小。代价是 U1 比 U3 早到几百度 ps—— 由 write leveling 给每颗单独补延迟（下方实验）。

Write Leveling 小实验

DDR3/4 初始化第一步 · 找到每条 DQS 相对 CK 的边界延迟

机制：控制器拖动 DQS 延迟，颗粒在每个 DQS ↑ 处采样 CK 电平并通过 DQ 回读；采样值在 0↔1 跳变的边界就是两沿对齐点，结果写回每条字节通道的 WL 寄存器。

读训练 · 眼图实验

拖动滑块看眼睛如何闭合 · 红十字 = 控制器寻找的最佳采样点
眼图张开度 66% · 余量充足

机制：初始化时控制器让颗粒回放训练图案（MPR），扫描接收延迟与参考电压 Vref，把采样点移到眼睛最中心——眼睛越开，温度/电压漂移的容忍度越大。

带宽计算器

Bandwidth Math

带宽 = MT/s × 位宽 ÷ 8 × 通道数。例题：LPDDR4X-3733 双通道（2 × 16 bit）= 3733 × 16 ÷ 8 × 2 ≈ 14.9 GB/s。 选好档位先算理论峰值，再对实测——差得太远就是没跑满（降频 / 单通道 / 训练失败）。

reg = <0x0 0x40000000 0x1 0x00000000>; /* 起点 1 GiB · 共 4 GiB */
};
reserved-memory { /* DSP/固件保留区 · no-map 对内核不可见 */
dsp_res: dsp@90000000 { reg = <0x0 0x90000000 0x0 0x04000000>; no-map; };
};
};
/* 容量对不上先查这里，再怀疑硬件（10 节踩坑 6）*/
三个高频坑：① U-Boot 显示 2 GiB、Linux 只见一半 → 八成是 memory 节点 reg 写错或 reserved-memory 划多了； ② memtester 会破坏数据，跑之前卸载应用或进单用户； ③ EDAC 的 ce_count 持续涨不是软件问题——记录 csrow/rank，降频复测（10 节踩坑 2/3）。

踩坑指南 · 症状 → 病因

Troubleshooting

调 DDR 的时间几乎都花在下面这些地方。台式机看上半张表，嵌入式看下半张。

不开机
启动循环
颗粒不在兼容列表 dram_para

SoC 厂的 DDR 初始化只对验证过的颗粒型号负责：换一颗不在 BOM/兼容表里的颗粒，时序参数全靠猜。表现：U-Boot 卡在 DRAM:、开机循环。修：查厂商兼容列表、更新 bootloader，必要时跑 DDR stress test 重新标定。

频繁
ECC 错误
CE 刷屏 · SI 余量或颗粒老化

EDAC 的 ce_count 持续上涨、偶发 UE：先降一档频率复测——错误消失就是信号余量问题（ODT 配置、走线、Vref）；降频仍错则怀疑颗粒/槽接触。csrow 信息能直接指到 rank。

高负载
随机死机
电源与温度余量不足

DDR 突发电流很大：VDD 纹波超标、VTT LDO 过载都会在重载时翻车。降频档（3200→2933）能稳 = 余量不足；仍死机 → 示波器量 VDD/VTT 纹波、查散热。手机平台还要查 DVFS 频点表是否越限。

点不亮
容量减半
金手指接触不良 台式机经典

氧化与灰尘是第一大因：断电后橡皮擦沿金手指单向擦几遍＋酒精清理＋吹槽，插到底听两声卡扣。多根内存用单根开机二分定位；容量减半常见于一条没插紧或一根槽损坏。

大负载死机
温度相关
BGA 焊点 / 过孔损伤 嵌入式

颗粒植球虚焊、HDI 过孔残带断裂，热胀冷缩触发：低温能跑、热了就崩。X-Ray/边界扫描定位，热风枪返修；设计侧保证颗粒下方与周围的过孔残带质量与应力释放。

容量
只认一半
位宽 / rank 配置错

x16 颗粒按 x8 配置、BA2 没接对、单 rank 当双 rank——地址映射直接错一半。嵌入式看 U-Boot bdinfo 的 memsize；Linux 侧再核 DTS memory 节点。两处不一致先信 bootloader。

混插
不稳定
不同速率/rank 混插

混插按最慢的那根跑，且双通道要求容量/rank 对称才是完整 128-bit（否则弹性双通道半速）。服务器 RDIMM 与 UDIMM 不可混插；频率档、CL 都以 SPD 里较低者协商。

休眠唤醒
数据损坏
自刷新时序问题

进 self-refresh 没确认完成就断电、或提前终止刷新：唤醒后随机数据错/变砖。查平台的 suspend 序列（CKE 时序、自刷新退出等待）；LPDDR 检查 deep sleep 与 PASR 的唤醒路径。

六条铁律

GOLDEN RULES
  • 1频率不够，沿来凑——DDR 的本名：上下沿各一拍
  • 2行要激活，用完预充——tRCD / tRP / tRAS 三件套
  • 3数据跟 DQS，命令跟 CK——源同步是高速并行总线的命
  • 4电容会漏，64 ms 一轮回；过 85 °C 刷新加倍
  • 5训练不过，一切白搭——write leveling 与读训练是点亮的门槛
  • 6带宽 = MT/s × 位宽 ÷ 8 × 通道——先算理论再对实测
