01

它是什么，为什么需要它

What & Why

一句话：RS-485 是 UART 的工业级电气层——帧格式、起始位、波特率全都还是 UART 那一套，只是把「单端对地电平」换成「双线电压差」，把「点对点」换成「多点总线」。

1983 年，EIA（后并入 TIA）发布 RS-485 / TIA-485-A 标准。它只定义电气层：一对差分线 A/B、 一个发送驱动器最多挂 32 个单位负载（unit load）、共模范围 −7 V ~ +12 V。 数据链路层一片空白——所以它天生就是「运载工具」：上面跑的几乎永远是 UART 帧， 工业现场则是 Modbus RTU（1979 年 Modicon 定义，2002 年后由 Modbus.org 维护的开放协议）。

为什么要差分？单端信号（如 RS-232）判断的是「线对地的电压」，地线上的噪声、两地间的电位差会直接叠进数据； 差分信号判断的是 VA − VB，两根线紧贴缠绕（双绞），噪声同时耦合到两根线上， 做差后抵消——共模噪声被拒之门外，这就是它能穿越电机柜与变频器的原因。

RS-485 是半双工总线：一对线分时收发，什么时候「开口」由收发器的 DE（Driver Enable）与 RE̅（Receiver Enable）引脚决定——这正是 03 节实验室的主角； 也可以像 RS-422 那样用两对线做全双工（4 线模式），但 Modbus RTU 标准总线只用两线。

FACT / A

它只是电气层 OSI L1

RS-485 不定义帧、地址、校验——那是 Modbus RTU 的事。所以「RS-485 线上跑什么」完全由你决定：UART 帧、DMX512、Profibus 物理层也基于它。

FACT / B

32 个单位负载 1/8 UL

每个收发器吸收 1 个单位负载（UL）。现代 1/8 UL 器件（如 SP3485 之外的低负载系列）可挂 256 个节点；加中继器还能更多。

FACT / C

±200 mV 判决门限 threshold

接收器只看 VA−VB：差值 < −200 mV 判为 1（Mark），> +200 mV 判为 0（Space），±200 mV 之间不确定——这就是失败安全偏置存在的意义（02 节）。

FACT / D

Modbus 只用两线 2-wire

Modbus over Serial Line 规定：1 个主机 + 最多 247 个从站地址，半双工两线制。地址 0 为广播。通信参数首选 8-E-1，无校验时建议 8-N-2。

* 单位负载：输入阻抗 12 kΩ 等效 1 UL；1/8 UL 器件 = 96 kΩ 输入阻抗 → 256 节点。

物理层 · 两根线扛住一个工厂

Physical Layer

A/B 差分对、共模范围、双绞与屏蔽、120 Ω 终端、失败安全偏置——RS-485 的可靠性全部来自这五个物理层决定。 每张卡片里是实时渲染的差分波形。

A / B差分对 · 双绞D+ / D−*

同一 UART 位在两根线上互为反相出现：一根升另一根必降。接收器做减法，只认差值不认对地电平。命名是行业著名泥潭：多数厂商 A=D+（Space 时更正），但有人相反——接反了整帧取反（09 节第一坑）。

Mark(1): V_A − V_B < −200 mV · Space(0): V_A − V_B > +200 mV
VA−VB差分电压DIFF

把两线做差后只剩三个世界：+2~5 V（0）、−2~−5 V（1）、±200 mV 之间（不确定）。驱动器必须在 54 Ω 负载上至少打出 ±1.5 V。中间那道灰色不确定区，就是无人驱动时的「漂移区」——偏置电阻的工作就是把空闲电平拉出这个区。

T3.5

帧的边界是「安静」

SILENCE
RTU 没有「报文头」与「报文尾」：接收方靠静默时间断帧——线路上安静超过 3.5 个字符时间（T3.5）即一帧结束；字符间安静超过 T1.5 则本帧作废。波特率 > 19200 时不再按公式，固定 750 µs。
CRC

CRC16-Modbus 速览

CHECKSUM
多项式 0x8005（发送时按反射 0xA001 右移实现）· 初值 0xFFFF · 结果低字节先发。覆盖地址到数据全部字节。逐位手算过程在 06 节计算器。
为什么地址 0x00 有特殊待遇：0x00 是广播地址——所有从站执行但不允许应答（否则 247 个从站同时开口就是总线大战）。主机广播写指令后要主动静默等 T3.5+，典型的用法是广播校时、同步启停。
05

Modbus 数据模型 · 四张表

Data Model

任何 Modbus 报文最终都是在读写下面四张表之一。它们只存在于从站固件里，地址空间各自独立、都从 0x0000 到 0xFFFF。

线圈

COILS读写 · 1 bit
继电器、指示灯、使能开关。ON = 0xFF00，OFF = 0x0000（写单线圈 FC05 的值域）。地址习惯记作 00001-65536（1 基十进制）。

离散输入

DISCRETE INPUTS只读 · 1 bit
按键、限位开关、故障干接点。物理上往往是光耦输入。地址习惯记作 10001-65536，只能被 FC02 读。

保持寄存器

HOLDING REGISTERS读写 · 16 bit
设定值、PID 参数、掉电保持的配置。Modbus 最核心的一张表，FC03 读 / FC06、FC10 写。地址习惯记作 40001-49999。

输入寄存器

INPUT REGISTERS只读 · 16 bit
ADC 采样、温湿度、电量累计——传感器测量值全在这。FC04 读。地址习惯记作 30001-39999。32 位浮点数占两个连续寄存器（大端或字交换，厂家说了算，09 节有坑）。

踩坑指南 · 症状 → 病因

Troubleshooting

RS-485 系统的故障几乎都在下面六个格子里。按症状对号入座，命中率从高到低。

A/B
接反
读到的是「镜像字节」· 0x55 ↔ 0xAA 互换

差分对反了 = 每一位都取反：起始位变高、停止位变低，接收端要么狂报帧错误，要么稳定解出错误字节（如 0xFF→0x00）。有的设备因此「偶尔能通」（恰好对称）。处方：交换 A/B 两线；拿万用表量空闲压差，偏置后 A−B 应约 +0.3 V。

长线
误码
没有终端电阻 · 反射叠加

波特率一高（≥ 38400）或线一长（> 50 m）就 CRC 错误刷屏，短线正常——信号在无终端长线上来回反射，边沿处叠出振铃。处方：仅在总线两端各并一只 120 Ω（02 节拓扑图）；中间节点严禁再挂终端。

报文前
粘垃圾
无失败安全偏置 · 空闲电平漂移

无人发送时总线高阻，接收器把噪声当起始位，吐出 0x00/0xFF 混进正常报文开头。处方：主机端加偏置电阻对（02 节计算器），让空闲差压 ≥ 300 mV；很多现代收发器内置全 1 失败安全，可一并确认。

响应
随机坏
地址冲突 · 两个从站同时应答

两个从站配了同一地址，每次被轮询都同时驱动总线，电平互相顶牛——表现为 CRC 错误时好时坏（取决于两边数据巧合程度）。处方：逐个上电扫码（mbpoll -a N -t 3 -r 1 -c 1），重新分配唯一地址。

整线
不通
波特率 / 校验 / 停止位不匹配

工厂设备常见 9600-8-E-1，适配器默认 19200-8-N-1——一个字节也解不出来，全是帧错误。这与 UART 乱码同根同源（电气层就是 UART）。处方：核对四要素；RTU 无校验时用 8-N-2 补足 11 位字符。

浮点数
读不对
32 位值的字序陷阱 · 大端 vs 字交换

一个 float 占两个寄存器，厂家可能高字在前（AB CD）也可能低字在前（CD AB），十进制看着像天文数字。处方：mbpoll -f（浮点）配合交换寄存器顺序重读一次；或读回 raw 十六进制手工拼。Modbus 只定义 16 位，32 位解释全是厂家方言。

GOLDEN RULES · 八条铁律
  • 1先抬 DE 再说话：DE 抬高后等 ≥1 bit 才能发首字节
  • 2发完再撒手：等最后停止位移出（TC 标志）才放下 DE
  • 3终端只挂两端：120 Ω × 2，中间节点只做短抽头
  • 4偏置只挂一处：主机端一对电阻，钉住空闲电平
  • 5A/B 别迷信丝印：D+/D− 厂家定义不一，空闲量压差定乾坤
  • 6四要素一致：波特率·数据位·校验·停止位（推荐 9600-8-E-1）
  • 7CRC 低字节在前：帧尾两个字节是 [Lo, Hi]
  • 8地址唯一 + 0 只广播：广播后主机保持静默等 T3.5
GLOSSARY · 术语表
Mark / Space
逻辑 1 / 0 的电报时代名字；RS-485 里 Mark 表示 V_A−V_B < −200 mV
Unit Load 单位负载
12 kΩ 等效输入阻抗 = 1 UL；标准总线 32 UL，1/8 UL 器件可到 256 节点
DE / RE̅
驱动器使能 / 接收器使能（低有效）；常并联成一个引脚做方向控制
Turnaround 换向
半双工总线从「发」切到「收」的过程，主机须在 T3.5 内完成
T3.5 / T1.5
帧间静默 3.5 字符 / 字符间最大间隔 1.5 字符；超 T1.5 的帧作废
PDU / ADU
协议数据单元（FC+数据）/ 应用数据单元（地址+PDU+CRC）
Slave Address
1-247 单播地址；0 广播；248-255 保留
Fail-safe Bias
空闲偏置：A 上拉、B 下拉，使无人发送时差压稳定为 Space
Trunk / Stub
干线（两端终端的菊花链主干）/ 抽头（节点接入线，应尽量短）
Isolated Transceiver
隔离型收发器（ADM2483 等），破解两地电位差超窗问题
